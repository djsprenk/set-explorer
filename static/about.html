Set Explorer

About Set Explorer

Set Explorer is a project about visualizing energy across DJ sets.

Inspired loosely by Fathom's Rocky Morphology project, it mines and combines data stored in Virtual DJ's (VDJ) database as well as data stored in Mixcloud to make it easer to search, explore, and select sets to listen to.

Technologies

  • Python for scripting and extracting data from VDJ.
  • Pandas for data sanitization / joining.
  • JS/D3 for rendering sets & timelines.
  • HTML/CSS for page content and styling.
  • Postman for pulling data from Mixcloud
